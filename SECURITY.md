# Security

Do not post credentials, serial numbers, personal information, or exploit details in public issues.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/djdiptayan1/ajazz-820-max-web/security/advisories/new). Include the affected commit, reproduction steps, impact, and a minimal example without secrets.

Only the current default branch is maintained. There is no guaranteed response or remediation timeframe.

This app can send HID reports only after browser device permission. Applying custom lighting may update persistent device state. Firmware flashing is not implemented. Do not run untrusted forks against your keyboard without inspecting their changes.
